
# Day 001 - Number of Sub-arrays With Odd Sum

- LeetCode: 1524
- Difficulty: Medium
- Language: Python 3
- Topic: Prefix Sum

## Problem
Count the number of subarrays whose sum is odd.

## Example
Input: [1, 3, 5]
Output: 4

## Approaches
1. Brute Force - Check all possible subarrays.
2. Optimized - Use prefix sum parity counting.

## Complexity

| Approach | Time | Space |
| Brute Force | O(n²) | O(1) |
| Optimized | O(n) | O(1) |

## Key Learning
Used prefix sum parity to count odd-sum
subarrays efficiently.
